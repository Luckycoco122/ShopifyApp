# 03. UI Spec

## Tono visual
- Calido y estrategico
- Menos "panel tecnico", mas "workspace creativo guiado"
- Priorizar claridad y confianza

## Pantalla: Dashboard
- Hero con propuesta de valor y CTA a "Nuevo proyecto"
- Tarjetas de metricas iniciales
- Grid de modulos:
  - copy de producto
  - SEO basico
  - email marketing
  - ofertas y branding
- Lista de proyectos ejemplo o recientes
- Estado del proveedor de IA

## Pantalla: Nuevo proyecto
- Cabecera clara con objetivo del flujo
- Wizard horizontal de 4 pasos
- Area principal con formulario del paso activo
- Aside con resumen del brief
- Panel final con preview del proyecto cuando se hace submit

## Requisitos de UX del wizard
- Siempre mostrar progreso
- Botones claros de siguiente, volver y crear brief
- Validacion ligera por paso
- Campos abiertos con ejemplos concretos

## Contenido por paso
### Producto
- nombre del producto
- categoria
- descripcion corta

### Cliente ideal
- perfil del cliente
- pains o necesidades
- nivel de conocimiento del problema

### Marca y tono
- nombre de marca
- preset de tono
- notas de voz

### Que generar
- checkboxes para:
  - copy de producto
  - SEO
  - email marketing
  - oferta
  - branding inicial

## Feedback
- Toast al crear el brief
- Panel de resultado con entregables y siguiente accion recomendada
- Mensaje explicito de que Anthropic aun esta en modo scaffold
