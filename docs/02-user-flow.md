# 02. User Flow

## Flujo principal
1. El merchant entra en Trazo desde Shopify.
2. Ve el dashboard con valor claro: que puede generar y que estado tiene la app.
3. Pulsa "Nuevo proyecto".
4. Completa el wizard:
   - define el producto
   - describe el cliente ideal
   - fija marca y tono
   - elige salidas a generar
5. Trazo crea un brief inicial.
6. El merchant revisa los entregables recomendados.
7. En una fase posterior, lanzara la generacion real.

## Estados clave
- Empty-ish: sin proyectos reales, pero con ejemplos y modulos para orientar
- Drafting: el merchant esta completando el wizard
- Brief ready: existe suficiente contexto para generar
- Generation pending: provider preparado pero no conectado

## Fricciones previstas
- El merchant no sabe describir su cliente ideal
- El merchant mezcla atributos del producto con claims de marketing
- El merchant selecciona demasiadas salidas sin tener una prioridad clara

## Mitigaciones
- Microcopy guiado en cada paso
- Resumen lateral del brief
- Selecciones por defecto razonables
- Preview final que aterriza el valor antes de cualquier llamada a IA

## Flujo alternativo
- El merchant llega al dashboard y aun no quiere generar
- Revisa casos de uso, modulos y el estado de integracion
- Decide volver mas tarde con la informacion necesaria
