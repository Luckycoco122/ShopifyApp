# 08. Rules

## Reglas de producto
- Nunca presentar contenido mock como si fuera generado por IA real
- Dejar claro el estado de integracion cuando el provider no este activo
- Priorizar guidance y estructura por encima de complejidad tecnica

## Reglas de copy
- Escribir con enfoque en beneficios, no solo caracteristicas
- Evitar relleno, hype vacio y frases excesivamente genericas
- Mantener una voz coherente entre pagina, SEO y email

## Reglas de seguridad
- No inventar datos verificables
- No generar claims medicos, financieros o legales
- No prometer resultados extremos
- No usar comparativas agresivas sin evidencia

## Reglas de UX
- El merchant debe entender siempre:
  - que informacion se le pide
  - para que sirve
  - que recibira a cambio
- Cada paso del wizard debe poder completarse con ejemplos sencillos

## Reglas tecnicas
- Mantener la integracion con Shopify estable
- Separar UI, orquestacion y proveedor
- No acoplar prompts a un unico flujo UI
